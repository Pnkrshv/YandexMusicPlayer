# Виджет Яндекс Музыки для панели задач Windows 11

Компактный плеер-виджет в стиле Windows 11: Mica-эффект, скруглённые углы,
акцентный цвет системы. Закрепляется над панелью задач в правом нижнем углу,
иконка в системном трее.

**Виджет управляет приложением «Яндекс Музыка»** через Windows SMTC API
(GlobalSystemMediaTransportControls) — тот же API, что используют
медиа-клавиши клавиатуры, Bluetooth-наушники и штатные виджеты Windows.

## Как это работает

1. Запустите приложение «Яндекс Музыка» на компьютере (как обычно).
2. Запустите этот виджет (`python main.py`).
3. Виджет автоматически найдёт активную медиасессию Яндекс Музыки.
4. В виджете отображается текущий трек, обложка, прогресс-бар.
5. Кнопки виджета управляют воспроизведением в приложении Яндекс Музыки.

**Не требует логина и пароля.** Виджет не обращается к API Яндекса
напрямую — он работает через системный медиа-интерфейс Windows.

## Возможности

- Автоматическое обнаружение приложения Яндекс Музыки
- Отображение названия, исполнителя, альбома и обложки трека
- Кнопки Play/Pause, следующий/предыдущий трек
- Прогресс-бар с перемоткой (клик в любом месте дорожки)
- Управление системной громкостью приложения (через pycaw, опционально)
- Иконка в системном трее с индикатором состояния
- Стилизация под Windows 11 (Mica, акцентный цвет, светлая/тёмная темы)
- Горячие клавиши для управления

## Требования

- Windows 10 (build 19041+) или Windows 11 (для Mica — build 22000+)
- Python 3.10 или новее
- Установленное приложение «Яндекс Музыка» для Windows
  (скачать: https://music.yandex.ru/download/)

## Установка

### 1. Установите Python

Скачайте установщик с https://www.python.org/downloads/windows/
При установке отметьте «Add Python to PATH».

### 2. Установите зависимости

Откройте PowerShell или командную строку в папке проекта и выполните:

```powershell
pip install -r requirements.txt
```

Для управления громкостью приложения (опционально):

```powershell
pip install pycaw comtypes
```

Если `pycaw` не установлен — кнопка громкости в виджете работать не будет,
остальной функционал работает.

### 3. Запустите виджет

```powershell
python main.py
```

В системном трее появится иконка, в правом нижнем углу над панелью задач —
компактный виджет.

## Использование

### Управление мышью

| Элемент | Действие |
| --- | --- |
| Клик по иконке в трее | Показать / скрыть виджет |
| Правый клик по иконке в трее | Контекстное меню |
| Перетаскивание виджета | Переместить в любое место экрана |
| Кнопка ▶ / ⏸ | Воспроизведение / Пауза в приложении |
| Кнопки ⏮ / ⏭ | Предыдущий / Следующий трек |
| Прогресс-бар | Клик — перемотать к точке |
| Ползунок громкости | Изменить громкость приложения (требует pycaw) |

### Горячие клавиши (когда виджет активен)

| Сочетание | Действие |
| --- | --- |
| `Ctrl+Alt+P` | Play/Pause |
| `Ctrl+Alt+N` | Следующий трек |
| `Ctrl+Alt+B` | Предыдущий трек |
| `Ctrl+Alt+M` | Показать/скрыть виджет |

> Глобальные горячие клавиши (работают даже когда приложение не в фокусе)
> можно подключить через библиотеку `keyboard` (`pip install keyboard`) —
> раскомментируйте соответствующий блок в `main.py`. Запуск потребуется
> выполнять с правами администратора.

## Устранение неполадок

**Виджет показывает «Яндекс Музыка не найдена»**

Убедитесь что:
1. Приложение «Яндекс Музыка» запущено (не браузер, а именно desktop-приложение).
2. В приложении начато воспроизведение (хотя бы на секунду) — SMTC регистрирует
   сессию только когда есть медиа.
3. В Windows Settings → System → Notifications → «Get notifications from
   apps and other senders» включено.

Виджет перепроверяет сессию каждые несколько секунд — запустите трек в
приложении, и виджет подхватит его автоматически.

**Кнопки не реагируют**

Проверьте в логах (запуск из консоли: `python main.py`), что SMTC нашёл
сессию. Если в логе строки вида `SMTC sessions: N, current=...`, значит
сессии есть, но Яндекс Музыки среди них нет. Попробуйте начать
воспроизведение и подождать 2-3 секунды.

**Обложка не отображается**

Некоторые треки не имеют обложки — в этом случае виджет показывает
плейсхолдер. Это нормально.

**«winsdk» не устанавливается**

`winsdk` требует Python 3.8+ и Windows 10+. Если у вас Python 3.13 и
возникают проблемы, попробуйте Python 3.11 или 3.12.

**Mica не работает**

Mica доступен только на Windows 11 build 22000+. На Windows 10 и старых
сборках Windows 11 виджет использует обычный фон.

**Проблемы с codec'ами (Windows N-версии)**

Не требуется — виджет не воспроизводит медиа сам, он только управляет
приложением Яндекс Музыки.

## Технические детали

### Почему SMTC, а не прямой API Яндекс Музыки?

1. **Не требует логина и пароля** — виджет не имеет доступа к аккаунту.
2. **Работает с любой версией приложения** — обновления API Яндекса не
   ломают виджет.
3. **Безопасно** — нет сетевых запросов к Яндексу, всё через локальный
   Windows API.
4. **Поддерживается 2FA и любые способы входа** в приложение Яндекс Музыки.

### Ограничения SMTC

- Нет API для лайка трека (используйте само приложение)
- Нет API для переключения очереди/плейлиста
- Нет API для управления очередью
- Положение и длительность обновляются не в реальном времени — виджет
  опрашивает позицию каждую секунду

## Сборка в единый .exe (опционально)

```powershell
pip install pyinstaller
pyinstaller --noconsole --onefile --name "YandexMusicWidget" main.py
```

Готовый файл появится в `dist/YandexMusicWidget.exe`.
